Setup steps
1. Create the Google Sheet
  1. Go to sheets.google.com and create a blank sheet.
  2. Rename the first tab to Trades.
  3. The script will auto-create the header row on first sync.
2. Paste the Apps Script
  1. In the Sheet: Extensions → Apps Script.
  2. Delete existing code, paste below, save.
3. Deploy as Web App
  1. Deploy → New deployment.
  2. Gear icon → Web app.
  3. Execute as: Me. Access: Anyone.
  4. Deploy, authorize, copy Web App URL.
  5. Paste above and Connect.

"Anyone" means the URL itself is the secret — don't share it.

4. Add to iPhone home screen
  1. Open this file in Safari.
  2. Share icon → Add to Home Screen.
